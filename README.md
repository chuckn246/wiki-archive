# Wiki Archive

This repository contains an archive of my former DokuWiki website (wiki.chucknemeth.com).

The site is no longer actively maintained. Some of the information may be outdated, incomplete, or incorrect for current software and systems. The content is preserved because older pages may still be useful as historical or technical reference material.


## Repository contents

The original DokuWiki content is stored under:
```
original/
├── pages/    # Original DokuWiki page source
└── media/    # Images and other uploaded files
```

The files under `original/pages/` use DokuWiki markup and have been preserved largely as they existed on the original site.


## Markdown Archive

The converted documentation is available in `docs/` and
published at <https://legacy.chucknemeth.com>.

The original DokuWiki pages and media are preserved
under `original/`.

The archive is read-only and is not actively maintained.


## Maintenance status

This repository is archived reference material and is not actively maintained.

I do not intend to keep the documentation current with newer versions of software, operating systems, applications, or hardware.

If you use information from this repository, verify that it is still applicable to your environment before relying on it.
