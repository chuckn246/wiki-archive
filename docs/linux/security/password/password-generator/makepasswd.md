# makepasswd

------------------------------------------------------------------------

## Description

Generate and/or encrypt passwords.

------------------------------------------------------------------------

## Install

- Install `makepasswd`:
  ``` bash
  sudo apt install makepasswd
  ```

------------------------------------------------------------------------

## Use

- Generate a password 40 chars long:
  ``` bash
  makepassword -chars 40
  ```
