# diceware

------------------------------------------------------------------------

## Description

Generate passwords from wordlists.

------------------------------------------------------------------------

## Install

- Install diceware:
  ``` bash
  sudo apt install diceware
  ```

------------------------------------------------------------------------

## Use

- Generate diceware password:
  ``` bash
  diceware
  ```
- Generate diceware password with 10 words:
  ``` bash
  diceware -n 10
  ```
- Generate diceware password using an asterisk as the delimiter:
  ``` bash
  diceware -d '*'
  ```
