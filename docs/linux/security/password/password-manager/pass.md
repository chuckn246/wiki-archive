# Pass

------------------------------------------------------------------------

## Description

Pass is a pretty cool password manager that encrypts your passwords with
gpg. It has some nice features and plugins.

------------------------------------------------------------------------

## Install

- Install pass:
  ``` bash
  sudo apt install pass
  ```
- Alternatively, another option is [gopass](https://www.gopass.pw/docs/)
  which is pass re-written in go.
