======keyring======

----



=====Description=====
**keyring** provides a way to store, lookup and delete passwords in various backends supported by Python-Keyring.

----

=====Install=====
====apt====
  * Install using apt:<code bash>
sudo apt install python3-keyring
</code>

====pip====
  * Install using pip:<code bash>
python3 -m pip install --user keyring
</code>


----
=====Usage=====
====Python====
You can set/get entries from a Python script or from the Python terminal

  * Add an entry:<code python>
import keyring
keyring.set_password("system", "username", "password")
</code>
  * Add an entry but prompt for password:<code python>
import keyring
keyring.set_password('twitter', 'xkcd', getpass.getpass())
</code>
  * Retrieve a password:<code python>
import keyring
keyring.get_password("system", "username")
</code>

----

====CLI====
You can set/get entries directly from the command line or from bash scripts, etc.

  * Set a password:<code bash>
keyring set SERVICE USERNAME
</code>
  * Retrieve a password:<code bash>
keyring get SERVICE USERNAME
</code>
  * Delete a password:<code bash>
keyring del SERVICE USERNAME
</code>
  * Show help:<code bash>
keyring --help
</code>

----

=====Details=====
The commands above will set the following attributes on an entry:
  * For example, set a twitter password:<code bash>
keyring set twitter chuckn246
</code>
  * Will create an entry with the Title:
    * Password for 'chuckn246' on 'twitter'
  * Will set these attributes on the entry:
    * **application**: Python keyring library
    * **service**: twitter
    * **username**: chuckn246

==Small Gotcha==
  * Note that the attribute username is different than the entry UserName (Note capitalization).<code bash>
secret-tool search service twitter
[/org/freedesktop/secrets/collection/TestDB/xxxxxxx]

=====Ansible=====

  * Create entry for ansible:<code bash>
keyring set ansible_vault ansible_user
</code>
  * Create a python script to decrypt vault files ''%%vim ~/.ansible/.vault_password%%'':<code python>
#!/usr/bin/env python3
import keyring
vault_password=keyring.get_password("ansible_vault", "ansible_user")
print(vault_password)
</code>
  * Make script executable:<code bash>
chmod 700 ~/.ansible/.vault_password
</code>
  * Edit ''%%ansible.cfg%%'':<code ini>
vault_password_file = ~/.ansible/.vault_password
</code>
