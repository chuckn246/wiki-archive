======Debian 10 Preseed======
Not much has changed since the Debian 9 preseed that I can tell.

This is a basic implementation of what is possible with preseeding.

----

=====Gathering Information=====
Investigating to see what can be preseeded was quite the learning experience! You quickly find out that there isn't much recent info readily available to figure these things out.
  * Start with the [[https://www.debian.org/releases/buster/example-preseed.txt|example preseed]]
  * You can run the following commands on an existing install for additional preseedable questions to browse:<code>
sudo debconf-get-selections --installer > filename
debconf-get-selections >> filename
</code>
  * A couple other files we can parse are located here on an existing install: 
    * ''%%/var/log/installer/cdebconf/templates.dat%%''
    * ''%%/var/log/installer/cdebconf/questions.dat%%''

====Filter Script====
I created this script to help me sort through the dat files (and to test my **awk** and **sed** skills). 

You can find it in my [[https://gitlab.com/preseed/preseed-scripts|gitlab repo]] as well.

  * Create a directory:<code>
mkdir ~/preseed && cd ~/preseed
</code>
  * Download the script:<code>
wget https://gitlab.com/preseed/preseed-scripts/raw/master/filterdat
</code>
  * Make the script executable:<code>
chmod +x filterdat
</code>
  * Copy the files to the new directory:<code>
sudo cp /var/log/installer/cdebconf/*.dat ~/preseed
</code>
  * Change owner:<code>
sudo chown $USER ~/preseed/*.dat
</code>
  * Run the script:<code>
./filterdat templates.dat
./filterdat questions.dat
</code>
  * Read the output:<code>
less ~/preseed/templates.dat.filtered
less ~/preseed/questions.dat.filtered
</code>
  * Here's the code:<file sh filterdat>
#!/usr/bin/env bash

outfile="$1.filtered"

# Only print the lines we want
filter_dat() {
  awk 'BEGIN { RS = "" ; FS = "\n" }
    {
      if ( $2 !~ /(text|error|note|title)/)
      { 
        print $1
        print $2
        print $3
        if ($4 !~ /UTF-8/) print $4
        if ($5 !~ /UTF-8/) print $5
        if ($6 !~ /UTF-8/) print $6
        if ($7 !~ /UTF-8/) print $7
      }
    }' $1
}

# Run filter_dat then pipe output to sed to strip all empty
# lines, then add one newline above Name and save it to a file
filter_dat $1 | sed '/^$/d; s/Name/\n&/g' > "$outfile"

printf '%s%s\n' 'Processing complete! The filtered file is: ' "$outfile"
</file>

=====Passwords=====
  * Set a cleartext password.<code>
d-i passwd/user-password insecure
d-i passwd/user-password-again insecure
</code>
  * You can expire the cleartext password at first login.<code>
# Expire it at the bottom of the file
d-i preseed/late_command string in-target passwd --expire chuck
</code>
  * Set the password encrypted within the preseed file itself.<code>
# Generate the password
mkpasswd -m sha-512 -S $(pwgen -ns 16 1) mypassword

# Set the password
d-i passwd/user-password-crypted password $6$UyIcAz99JRIjOF9d$R/x4Z6JgS0ICE5U/VhIyqKMMK29aPhlBfj1MXuFuww9i9ry9fLVy/LzfO4QPExAWAYZX97euihMU8yHtmF4wI0
</code>

=====Installing Additional Applications=====
Here's a couple ways to install some additional programs.
  * In the //###Package Selection// section:<code>
d-i pkgsel/include string firmware-amd-graphics \
  firmware-linux-nonfree firmware-misc-nonfree git intel-microcode libgl1-mesa-dri \
  linux-headers-amd64 mesa-utils openssh-server pulseaudio vim xorg
</code>
  * At the end:<code>
d-i preseed/late_command string \
  in-target apt-get install firmware-amd-graphics \
  firmware-linux-nonfree firmware-misc-nonfree git intel-microcode libgl1-mesa-dri \
  linux-headers-amd64 mesa-utils openssh-server pulseaudio vim xorg
</code>

I'm sure there are other ways, but those two are what has worked for me so far.

====Running Commands====
You can also run commands on the target system. Here's some examples:
<code>
d-i preseed/late_command string \
  mkdir -p -m 700 /target/home/chuck/.ssh; \
  echo "ssh-ed25519 YOURxwxPUBLICxxxSSHxyxKEYxzx" > /target/home/chuck/.ssh/authorized_keys; \
  in-target chown --recursive chuck:chuck /home/chuck/.ssh; \
  in-target chmod 0644 /home/chuck/.ssh/authorized_keys; \
  in-target update-alternatives --set editor /usr/bin/vim.basic; \
  in-target passwd --expire chuck
</code>

===Notes===
  * The new filesystem is available at ''%%/target%%'' so you can copy/create/modify the files there:<code>
d-i preseed/late_command string mkdir -p -m 700 /target/home/chuck/.ssh</code>
  * You can chroot into the system:<code>
d-i preseed/late_command string chroot /target <commands></code>
  * You can chain commands together using a semicolon ''%%;%%''
    * Make sure the last command does **not** have a semicolon.
  * If your commands fail, you can check why by viewing the log screen with F4.

====Add it to the ISO====
https://wiki.debian.org/DebianInstaller/Preseed/EditIso

I used the following packages to complete these steps:
  * ''%%xorriso%%''
  * ''%%isolinux%%''
  * ''%%zip%%''
  * ''%%unzip%%''

===Steps=== 
  * Download a Debian iso
  * Rename it to debian.iso
  * Make a directory to hold the extracted iso:<code>
mkdir isofiles</code>
  * Extract ISO to the isofiles directory:<code>
xorriso -osirrox on -indev debian.iso -extract / isofiles</code>
  * Add write permissions to initrd:<code>
chmod +w -R isofiles/install.amd</code>
  * Unzip initrd:<code>
gunzip isofiles/install.amd/initrd.gz</code>
  * Add preseed to the initrd:<code>
echo preseed.cfg | cpio -H newc -o -A -F isofiles/install.amd/initrd</code>
  * Re-zip initrd:<code>
gzip isofiles/install.amd/initrd</code>
  * Remove write abilities of initrd:<code>
chmod -w -R isofiles/install.amd</code>
  * Enter isofiles directory:<code>
cd isofiles</code>
  * If you want to have a "zero interaction" install, do the [[#zero-interaction|zero interaction]] steps first.
  * Generate new md5sum.txt:<code>
chmod 666 md5sum.txt
find -follow -type f -exec md5sum {} \; > md5sum.txt
chmod 444 md5sum.txt</code>
  * Move back a directory:<code>
cd ..</code>
  * Generate new iso:<code>
xorriso -as mkisofs \
-isohybrid-mbr /usr/lib/ISOLINUX/isohdpfx.bin \
-c isolinux/boot.cat \
-b isolinux/isolinux.bin \
-no-emul-boot \
-boot-load-size 4 \
-boot-info-table \
-eltorito-alt-boot \
-e boot/grub/efi.img \
-no-emul-boot \
-isohybrid-gpt-basdat \
-o preseed-debian.iso \
isofiles/
</code>

===Install using the ISO===

Take the generated iso (preseed-debian.iso if you’re using the commands from above) and write it to a USB jump drive or upload it to Proxmox.

Boot the computer/VM from it and at the menu, select **Advanced Options > Automated Install**.

Wait a few seconds and it should start the installation process!

If you don't feel like navigating the menu and selecting the Automated Install, follow the [[#zero-interaction|zero interaction]] steps!

====Host it Locally====
  * Move into the directory with your preseed file on the host pc:
    * ''%%cd ~/preseed/%%''
  * Start a simple http server:
    * ''%%python3 -m http.server%%''
  * Start an installation on the target pc   
  * Two options:
    * Select **Advanced Options > Automated Install**
      * Set the ip and location of the file when prompted. Eg:
      * ''%%http://xxx.xxx.xxx.xx:8000/preseed.cfg%%''
    * Press <key>esc</key>
      * at the boot prompt:
      * ''%%auto url=xxx.xxx.xxx.xx:8000/preseed.cfg%%''

<WRAP info smaller>Make sure your firewall ports are open to allow access to port 8000 (or whatever port you have the http.server set to). 
You should see the GET request on the computer hosting the file if it all worked out.</WRAP>

====Zero Interaction====
You can configure the iso file so all you have to do is boot the machine with the iso inserted. 

It will automatically select the Automated Install option from the menu and proceed with the install.

===Steps===
<WRAP info smaller>This should be done before generating the md5sums in the [[#add-it-to-the-iso|above steps]] of adding the preseed to the iso.</WRAP>
  * Change permissions to allow writing of these files:<code>
chmod +w isofiles/isolinux/{gtk.cfg, isolinux.cfg}</code>
  * Edit: ''%%vim isofiles/isolinux/gtk.cfg%%''<code>
default auto
label auto
	menu label ^Automated install
        menu default
	kernel /install.amd/vmlinuz
	append auto=true priority=critical vga=788 initrd=/install.amd/initrd.gz --- quiet
</code>
  * Edit: ''%%vim isofiles/isolinux/isolinux.cfg%%''<code>
# D-I config version 2.0
# search path for the c32 support libraries (libcom32, libutil etc.)
path 
include menu.cfg
default vesamenu.c32
prompt 0
timeout 1
autoselect auto
</code>
  * Reset permissions:
    * ''%%chmod -w isofiles/isolinux/{gtk.cfg, isolinux.cfg}%%''
  * Continue with the [[#add-it-to-the-iso|above steps]] continuing from generating the md5sums.
